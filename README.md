## Project idea

This is the capstone project for the *Time Series Forecasting for AI Systems* programme: a single Colab notebook that takes one retail demand series from raw data to a validated, uncertainty-aware forecast, following the backtested-forecasting-report structure used throughout the course.

## Dataset

**`data/retail_demand.csv`** — daily unit sales across 6 series (`region` × `category`), with strong weekly and yearly seasonality plus promotional shocks.

This project uses the **Riyadh / Grocery** series specifically. It was chosen because it shows clean weekly seasonality and a stable, non-intermittent demand pattern (no zero/near-zero rows), which makes it a good fit for comparing a classical seasonal model (SARIMA) against a tree-based model (LightGBM) on equal footing, without the added complications of a structural break (`workforce_demand.csv`), a short low-frequency history (`economic_indicator.csv`), or heavy intermittency (`intermittent_demand.csv`).

This is synthetic course data, generated by `data/generate_series.py` — it does not describe any real retailer.

## What the notebook does

`riyadh-grocery-demand-forecast.ipynb` runs top to bottom and covers:

1. **Decomposition & diagnostics** — STL decomposition (trend/seasonality/residual), ACF/PACF plots, and an ADF stationarity test on the raw and differenced series.
2. **Classical model** — a SARIMAX model (seasonal period 7) with a Ljung-Box residual check.
3. **ML/GBM model** — a LightGBM regressor with engineered lag, rolling-window, and calendar features, forecasting recursively over a multi-day horizon.
4. **Walk-forward backtest** — a 5-fold expanding-window backtest via `common/backtest.py`, comparing a seasonal-naive baseline, SARIMA, and LightGBM.
5. **Accuracy metrics** — MAE, RMSE, and MASE (scale-free, appropriate since this series has no zero/near-zero values) via `common/metrics.py`.
6. **Probabilistic forecast** — SARIMA prediction intervals at the 80% nominal level, scored with both empirical coverage and mean interval width.
7. **Model comparison** — which model the backtest results support deploying for this series.

## How to run it

Click the **Open in Colab** badge above. The first code cell installs all dependencies (`pandas`, `numpy`, `matplotlib`, `statsmodels`, `scikit-learn`, `lightgbm`) and fetches `common/metrics.py`, `common/backtest.py`, and `data/retail_demand.csv` directly from this repository — no manual setup or local clone is required.

To run it locally instead:

```bash
git clone https://github.com/manaralbader/retail-demand-forecast.git
cd retail-demand-forecast
pip install pandas numpy matplotlib statsmodels scikit-learn lightgbm jupyter
jupyter notebook riyadh-grocery-demand-forecast.ipynb
```
